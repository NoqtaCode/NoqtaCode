# NoqtaCode

موقع عربي باتجاه RTL للتعريف بخدمات NoqtaCode في الحلول الرقمية. يشمل حاليًا معلومات الخدمات، وباقات بناء المواقع، ومعرض الأعمال، ومقدّر تكلفة مبدئيًا، ومقالات، وأسئلة شائعة، ووسائل تواصل مباشرة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## الفحص والبناء

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

ينشئ أمر `npm run build` الملفات الجاهزة للنشر داخل مجلد `dist`.

## المسارات

- `/` الرئيسية
- `/services` الخدمات
- `/estimator` مقدّر التكلفة
- `/portfolio` أعمالنا
- `/about` من نحن
- `/contact` التواصل
- `/blog` المدونة
- `/faq` الأسئلة الشائعة

## النشر والاستضافة

الموقع Frontend فقط ولا يحتاج إلى خادم تطبيقات أو قاعدة بيانات. ارفع محتويات `dist` إلى استضافة مواقع ثابتة، واضبطها لإعادة توجيه المسارات غير الموجودة إلى `index.html` حتى تعمل روابط الصفحات عند فتحها مباشرة أو تحديثها.

نموذج التكلفة يعمل داخل المتصفح. روابط التواصل تفتح واتساب أو تطبيق البريد ليُراجع الزائر الرسالة ويرسلها بنفسه؛ لا يرسل الموقع البيانات تلقائيًا ولا يخزنها.

قبل النشر، راجع أرقام الباقات وتفاصيل ما تشمله، وروابط المواقع الاجتماعية والمواقع المعروضة، وتأكد من اعتماد شعار وهوية الشركة النهائية.
